1. Скопировать файл на компьютер. В флешки запустить программу не удастся
2. Разрешить запуск файла MeatecCncStoneUpdate_*.run как программы. Properties / Permissions / Allow executing file as program
3. Правая кнопка мышки на файле / Run
4. Программа скажет, что указанная папка существует и что все файлы в ней будут удалены. Согласиться на удаление
