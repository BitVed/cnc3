Contour Editor

Bottom Panel

Buttons

  • Home

    Go to the Home Panel.

  • Open

    Open a project.

  • Save

    Save current project.

  • Save as

    Save as a copy or new file.

  • Load DXF

    Load a cutting contour in the DXF format. Layer 0 is the XY plane (bottom plane of the workpiece), layer 1 is the UV plane (top plane of the workpiece, optional). Only line and arc segments are supported in the DXF file.

  • Passes - adjust contour parameters and cutting modes

    Set up wire offsets and cutting modes.

  • Generate

    Generate the G-code program based on the contour and cutting settings. After successful generation, the program goes to the Work Panel.

Contour Edit Panel

Buttons

  • Entry line - add a new cutline before the first segment

    The entry line will be attached to the first contour point marked with a red square on the plot.

  • Delete - delete the selected contour from the project

  • Clear - delete all contours from the project

  • Set First - set selected segment as the first in the contour

  • Change Direction

    Reverse the segments' order in the contour. This operation changes the cutting direction.

  • Меню Edit

    • Use as Entry Line

      Use the selected contour segment as the entry line.

    • Rotate

      Rotate the selected contour by a given angle.

    • Flip Left-Right

      Flip the selected contour from left to right.

    • Flip Upside-Down

      Flip the selected contour upside down.

    • Resize

      Resize the selected contour.
